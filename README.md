## Quy Trinh

1. Điền thông tin sách đăng ký vào file Google Sheets/Form được cung cấp để tránh trùng lặp
2. Xây dựng sách theo tiêu chuẩn DAISY với quy định đã được đề cập
3. Đối với các cuốn sách có kích lớn như “Đại Việt Sử Ký Toàn Thư”, có thể chia thành các phần nhỏ hơn như chương, hồi:
└── MSHV1_MSHV2_MSHV3/
    ├── Tên_sách_1-Chương 1/
    │   ├── Tên_sách.zip <- Bao gồm các file .xml, .smil, .mp3, .opf và .ncx (nếu có)
    │   └── Tên_sách_sha256sums.txt <- Hash SHA-256
    └── Tên_sách_1-Chương 2/
        ├── Tên_sách.zip
        └── Tên_sách_sha256sums.txt
4. Đối với các cuốn sách được chia thành các chương, hồi thì vẫn giữ mã ISBN
5. Kiểm tra chất lượng sách (audio + lỗi chính tả)
6. Nộp sách theo thời gian được thông báo 30/9
